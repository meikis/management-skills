# 管理日常动作技能包（management-skills）

> 6 个 AI Skill，把派活、请示、交付自检、责任锁定、带人、目标管控变成 AI 可自动执行的操作卡。
> 适用于 CatPaw / Claude Code / Minis 等支持 SKILL.md 规范的 AI Agent。

## 这是什么

一套面向一线管理者的 AI 辅助技能。不是理论课件，不是知识库——而是**你在管理动作发生的瞬间，AI 直接帮你干**的工具包：

- 派活时 → 逐条检查你有没有说清，补出可直接发的话术
- 请示时 → 帮你把"一个问题+三个方案+一个建议"补齐
- 交方案前 → 判定你的交付物在"及格/达标/超值"哪一层，给出跳层动作
- 开会分工时 → 检查责任有没有落到人头、权责利对不对等
- 带人时 → 按八步排出培养计划，每步给话术
- 定目标时 → 按五因素推演三档目标，检查三类对齐

每个 skill 均含：**触发条件 · 核心模型 · 检查清单 · 话术模板 · 示例 · 踩坑提醒**。

## 各技能速览

### Skill 1：任务派发检查器

```
你在做：给下属派活
AI帮你：五清楚逐条检查 → 补全缺失项 → 生成可发送话术

输入："让小张把车间那批探伤报告整理一下，尽快。"
输出：五清楚 0/5 检查 + 补全的派活话术（含一对一责任人/截止/验收标准）
关键：结果定义用名词不用动词——"交一份报告"可验收，"整理一下"不可验收
```

### Skill 2：请示与汇报教练

```
你在做：向上请示汇报 / 向下回应下属提问
AI帮你：
  向上：131请示法 = 1个问题 + 3个方案（做法/利/弊/投入）+ 1个最优建议
  向下：判断紧急度/能力/复杂度 → 选四种回应方式之一
        （直接告知 / 给方向不给答案 / 教练式提问 / 反问+授权）
  防责任跳跃：下属没想就来问 → 先要方案
```

### Skill 3：结果分层自查

```
你在做：交方案/报告/材料前自检
AI帮你：判定你在哪个圈层 + 给跳层动作清单

基本圈（做了=应该的）→ 期望圈（做到了要求=合格）→ 超值圈（超出预期=惊喜）
跳层公式：补齐缺失 + 提供决策建议 / 预判风险 / 可复用工具 / 数据说话 / 换位思考
九段体系：秘书 递名片→老板智囊；销售 记客户→建生态；班组长 看现场→育文化
```

### Skill 4：责任锁定与承诺管理

```
你在做：开会定任务、项目启动、跨部门分工
AI帮你：四组检查 + 生成任务锁定表 + 会议收口话术

四组检查（A 一对一锁定 + B 责权利等边三角形 + C 承诺式管理八特征 + D 越级规则）
越级规则：可越级检查不可越级指挥，可越级申诉不可越级汇报
输出：清单得分 + 任务锁定表 + 会议收口话术
```

### Skill 5：带人教练流程

```
你在做：带新人、培养骨干、交接
AI帮你：排八步培养计划 + 每步给话术 + 考核绑定提醒

八步：我做你看 → 你做我看 → 我点评 → 我再做 → 你再做 → 再点评 → 放手独立做 → 总结并教会他人
口诀："我说你听，你说我听；我做你看，你做我看；你放手做，你教别人。"
第8步是关键：能教别人才算真正学会，同时实现人才批量复制
```

### Skill 6：目标对齐与过程管控

```
你在做：定目标、跨部门排期、过程复盘
AI帮你：五因素推演三档目标 + 三类对齐检查 + PDCA八步

定目标：五因素推演（前三年产值 + 行业情况 + 实际产能 + 新客户订单 + 管理水平）
         输出三档：保守 / 合理 / 挑战，各附前提条件
对齐：上下对齐 + 水平对齐 + 客户对齐
过程：定目标 → 追过程 → 拿结果
      PDCA八步：找问题→找原因→定方案→定计划→执行→检查→标准化→持续改进
⚠️ 标准化涉及参数表变更必须走审批流程
```

## 安装

**CatPaw**：将 `skills/` 下各目录复制到 `~/.agents/skills/`。

**Claude Code**：复制到项目 `.claude/skills/` 或全局 `~/.claude/skills/`。

**Minis（Android）**：复制到 `/var/minis/skills/`，重启会话生效。

```bash
# CatPaw / Claude Code（macOS & Linux）
cp -r skills/* ~/.agents/skills/      # CatPaw
cp -r skills/* ~/.claude/skills/      # Claude Code 全局

# Windows PowerShell
Copy-Item -Path skills\* -Destination "$env:USERPROFILE\.agents\skills\" -Recurse

# Minis（Android）
cp -r skills/* /var/minis/skills/
```

## 使用示例

安装后无需手动调用。当你描述相关场景时，AI 助手会自动识别并激活对应技能：

```
你："让小张把车间那批探伤报告整理一下，尽快。"
→ task-dispatch-checker：五清楚 0/5 检查 + 补全的派活话术（含责任人/截止/验收标准）

你："小李来问：客户要退 5 台货，怎么办？"
→ briefing-coach：判定责任跳跃 + 教练式三连问 + 跟踪点

你："明天汇报的季度质检总结，就这几段：合格率 98.2%，比上季好，下季继续努力。"
→ result-layer-check：判定基本圈 + 跳层动作清单（补数据→拆归因→定量化目标→预判风险）

你："下周安全检查，我们几个一起弄一下，有问题找我。"
→ responsibility-lock：检出"我们几个"责任稀释 + 修正为单责任人 + 会议收口话术

你："小王要接手皮带撕裂检测的现场调试，怎么带？"
→ coaching-eight-steps：八步培养计划表 + 第1步话术 + 考核绑定提醒

你："明年产值目标定多少合适？去年 4200 万。"
→ goal-alignment-pdca：五因素推演表 + 保守/合理/挑战三档 + 待补数据清单
```

## Skill 编写规范

- 每个 skill = 目录 + `SKILL.md`（必需，AI 读取）+ `README.md`（人类文档）
- `SKILL.md` 需 YAML frontmatter：`name` + `description`
  - `description` 内含全部触发词，是 AI 匹配的主要机制
  - 正文用祈使句，控制在 80 行内
  - 只写模型不具备的知识（流程、清单、话术、企业规则）
- `README.md` 是面向人类的项目页，含背景、检查项、示例、安装说明
