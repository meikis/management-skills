# 目标对齐与过程管控（goal-alignment-pdca）

定目标用五因素推演，对齐用三类检查，过程用"定目标—追过程—拿结果"+ PDCA 八步管控与标准化沉淀。

## 对应培训模块

目标五大功能 · 目标对齐三类 · PDCA · 执行管控三关键词 · 稻盛和夫方程式（思维层/方法层）

## 触发条件

定年度/季度目标、启动项目、跨部门排期、过程检查或复盘。触发词：`定目标` `年度目标` `季度目标` `目标对齐` `复盘` `PDCA` `追过程` `启动项目` `排期`

## 一、定目标：五因素推演

| 因素 | 看什么 | 缺失时问用户 |
|------|--------|-------------|
| 前三年产值 | 趋势线（增长/持平/下滑） | "近三年数字各是多少？" |
| 行业情况 | 行业增速、政策、行情 | "行业今年整体涨跌？" |
| 实际产能 | 人/机/线的真实上限 | "满负荷能出多少？瓶颈在哪？" |
| 新客户订单 | 已签+在谈的确定性 | "新订单有把握的多少？" |
| 管理水平 | 执行力、良率、去年完成率 | "去年目标完成率多少？" |

输出：目标建议值 = 基准 × 行业系数 ± 产能约束 ± 新订单增量，分**保守/合理/挑战**三档并写明前提条件。

## 二、对齐：三类检查

- **上下对齐**：每项目标写明支撑上一级哪个目标
- **跨部门水平对齐**：接口、排期、责任书面确认（对照 responsibility-lock 的一对一锁定）
- **客户对齐**：目标回应客户真实需求/订单承诺

## 三、过程管控：PDCA 八步

1. 分析现状找问题（用数据） 2. 分析原因（鱼骨图/5Why） 3. 找主因（80/20） 4. 制定 5W1H 计划（验收标准写死） 5. 执行（一对一锁定责任人） 6. 检查效果（不达标回到 2） 7. 标准化沉淀（写进 SOP/参数表） 8. 遗留问题转入下一循环

⚠️ 第 7 步涉及**参数表的变更必须走审批流程**，防止未测试随意修改。

过程检查频率：年度→季度检查+月度跟踪；季度→月度检查+双周跟踪；项目→周检查+日站会（可选）。

## 输出物

目标推演表 / 对齐检查表 / PDCA 检查表（含检查节点），结论先行、数据缺失项标注"待用户提供"并给置信度。

## 示例

输入："明年产值目标定多少？去年 4200 万，前年 3800，大前年 3500。"

输出：合理档 4800 万（保守 4500 / 挑战 5200）；行业、产能、新订单待补（置信度 6/10 ⚠️）；三档前提条件各是什么；下一步补齐两个数 3 天内定档，定档后走三类对齐。

## 踩坑提醒

1. 定目标只看历史不看未来 → 五因素缺一不可
2. 上下对齐只传数字不传逻辑 → 下面不知道"为什么是30%"
3. 定完目标不追过程 → "追过程"才是管理者的日常
4. PDCA只做到C不做A → 检查完不标准化=白检查
5. 把"做了"当"做成了" → 做了是动作，做成了是结果

## 硬规则

所有目标数字必须可追溯到五因素之一，不接受"感觉/去年就这样"。
