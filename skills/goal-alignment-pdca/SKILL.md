# 目标对齐与过程管控（五因素 + 三对齐 + PDCA）

核心原则：定目标—追过程—拿结果。目标不是拍数字，是推演出来的承诺。
稻盛和夫方程式：结果 = 思维方式 × 热情 × 能力（思维方式为负，越努力越糟——先确认方向对）。

## 一、定目标：五因素推演

| 因素 | 看什么 | 缺失时问用户 |
| --- | --- | --- |
| 前三年产值 | 趋势线：增长/持平/下滑 | "近三年数字各是多少？" |
| 行业情况 | 行业增速、政策、行情 | "行业今年整体涨跌？" |
| 实际产能 | 人/机/线的真实上限 | "满负荷能出多少？瓶颈在哪？" |
| 新客户订单 | 已签+在谈的确定性 | "新订单有把握的多少？" |
| 管理水平 | 团队执行力、良率、交付力 | "去年目标完成率多少？" |

输出：目标建议值 = 基准（前三年）× 行业系数 ± 产能约束 ± 新订单增量，标注**保守/合理/挑战**三档，说明每档的前提条件。

## 二、对齐：三类检查

- [ ] **上下对齐**：个人/部门目标逐级支撑公司目标（每项写明"支撑上一级哪个目标"）
- [ ] **跨部门水平对齐**：依赖部门的接口、排期、责任已书面确认（对照 responsibility-lock 的一对一锁定）
- [ ] **客户对齐**：目标是否回应客户真实需求/订单承诺（内部目标 ≠ 客户价值的要标出）

## 三、过程管控：执行三关键词 + PDCA 八步

执行管控三关键词：**定目标 → 追过程 → 拿结果**（把"做了"当"做成了"是最大误区）。

| 步 | 阶段 | 做什么 |
| --- | --- | --- |
| 1 | P-计划 | 分析现状，找出问题（用数据，不用感觉） |
| 2 | P-计划 | 分析原因（鱼骨图/5Why，连问5个为什么） |
| 3 | P-计划 | 找出主要原因（80/20） |
| 4 | P-计划 | 制定计划：5W1H，验收标准写死 |
| 5 | D-执行 | 执行计划（按 responsibility-lock 锁定责任人） |
| 6 | C-检查 | 检查效果（对照第4步验收标准，不达标回到2） |
| 7 | A-标准化 | 标准化沉淀（有效做法写进 SOP/参数表/检查表） |
| 8 | A-改进 | 遗留问题转入下一个 PDCA 循环 |

⚠️ 第 7 步涉及**参数表的变更必须走审批流程**，防止未测试随意修改。

过程检查频率：年度目标→季度检查+月度跟踪；季度目标→月度检查+双周跟踪；项目目标→周检查+日站会（可选）。

## 工作流程

1. 判断用户处于哪一环：定目标 → 走五因素；对齐/排期 → 走三对齐；过程检查/复盘 → 走 PDCA 八步。
2. 信息不足先列推演表（已知/未知/需用户提供），给出带置信度的初步值，不瞎编数字。
3. 输出可执行产物：目标推演表 / 对齐检查表 / PDCA 检查表（含检查节点日历）。
4. 结尾提示下一个动作（如"下次检查点 10-20，届时提醒复盘第 6 步"）。

## 输出格式

```
【环节】定目标 / 对齐 / 过程管控
【结论先行】<目标建议值（三档）或当前 PDCA 步骤与判定>
【依据】逐项数据来源，缺失项标注"待用户提供"
【前提条件】各档目标分别需要什么条件成立
【下一步】<动作 + 时间 + 责任人>
```

## 示例

用户："明年产值目标定多少合适？去年 4200 万，前年 3800，大前年 3500。"

```
【环节】定目标
【结论先行】合理档 4800 万（保守 4500 / 挑战 5200）
【依据】
- 前三年：3500→3800→4200，年均 +9.5%，基准 4600
- 行业情况：待提供（当前按 +0% 计，置信度 6/10 ⚠️）
- 实际产能：待提供——若产能上限 5000 万，挑战档 5200 不可行
- 新客户订单：待提供
- 管理水平：待提供（去年目标完成率？）
【前提条件】保守档=现有客户不丢；合理档=新签订单 2 单落地；挑战档=产能瓶颈解除+行业回暖
【下一步】补行业判断与产能上限两个数，3 天内定档；定档后走三类对齐
```

## 踩坑提醒

1. **定目标只看历史不看未来** → 五因素缺一不可，尤其是行业变化和管理提升空间。
2. **上下对齐只传数字不传逻辑** → 下面只知道"要增长30%"，不知道"为什么是30%"，无法自主决策。
3. **定完目标不追过程** → "定目标"只是起点，"追过程"才是管理者的日常。
4. **PDCA只做到C不做A** → 检查完不标准化=白检查，同样的问题下轮还会犯。
5. **把"做了"当"做成了"** → 做了是动作，做成了是结果，拿结果才是终点。

## 硬规则

- 所有目标数字必须可追溯到五因素之一，不接受"感觉/去年就这样"。
- 第 7 步标准化沉淀涉及参数表时，提醒走生产变更管控审批，防止未测试随意修改。
