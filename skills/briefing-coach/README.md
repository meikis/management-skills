# 请示与汇报教练（briefing-coach）

双向教练：向上用 131 请示法补齐内容，向下判断管理者回应请示的四种方式，防止责任跳跃。

## 对应培训模块

131 请示法 · 管理者应对请示四方式 · 责任跳跃定律（方法层/责任层）

## 触发条件

- 向上：用户要向领导请示/汇报。触发词：`请示` `汇报` `向领导` `找老板` `131`
- 向下：下属来问问题，用户要回应。触发词：`下属问` `怎么回应` `答复下属`

## 向上：131 请示法

**1 个问题**（只聚焦一个决策点）+ **3 个方案**（做法/利/弊/投入）+ **1 个最优建议**（明确表态并给理由）。

汇报（非请示）降级为：1 个结论 + 3 个支撑事实 + 1 个下一步请求。

输出格式：

```
【请示主题】<一句话>
【背景】<3 行内，只说领导决策需要的信息>
【问题】<唯一决策点：请批 A 还是 B>
【方案一】做法 / 利 / 弊 / 投入
【方案二】做法 / 利 / 弊 / 投入
【方案三】做法 / 利 / 弊 / 投入
【我的建议】方案 X，理由：……（含不选其他两项的原因）
【需要您支持】<需要领导拍板/给资源/协调的事项>
```

## 向下：四种回应方式

| 情形 | 回应方式 | 话术要点 |
|------|----------|----------|
| 十万火急（安全/停产/客户炸了） | 直接告知答案 | "按 X 执行，先止损，24 小时内补复盘" |
| 紧急不难 | 给方向不给答案 | "方向是 X，怎么做你定，半小时后报方案" |
| 日常 | 教练式提问 | "你怎么看？还有呢？还有呢？"（至少三问） |
| 不紧急且重要 | 反问+授权 | "你先出个方案再找我，按你的判断办" |

教练式提问四层句式：① 了解想法 → ② 扩展思考 → ③ 推动决策 → ④ 确认承诺。

响应前必查**责任跳跃**：
- 对方没想就来问 → 先要方案
- 替他做了决定 → 退回教练式提问
- 责任跳跃定律：谁的责任谁扛，上级代做一次，责任就永久跳一级

## 输出物

- 向上：可粘贴的 131 成文（标注补全部分）
- 向下：分级判断理由 + 具体问句（≥3 个）+ 事后跟踪点

## 示例

输入："小李来问：客户要退 5 台货，怎么办？"

判定：日常事务 + 对方无方案即来问（责任跳跃）→ 教练式提问：
1. "客户退的真实原因是什么？查过吗？"
2. "你觉得有几种处理方式？还有呢？"
3. "如果你拍板，你选哪个？为什么？"
跟踪点：2 小时内带回书面方案再批。

## 踩坑提醒

1. 每次都直接给答案 → 下属越来越依赖你，你越来越累
2. 十万火急还在"你怎么看" → 火烧眉毛时直接下令
3. 问了不给反馈 → 教练式提问后要确认"那你打算怎么做"
4. 该授权的不放手 → 下属职责范围内的事还替他决定，他永远长不大
