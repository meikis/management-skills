# 带人教练流程（八步教练法）

核心原则：人才是复制出来的，不是喊出来的。教=示范+反馈+放手+再教。
口诀："我说你听，你说我听；我做你看，你做我看；你放手做，你教别人。"

## 八步流程

| 步 | 动作 | 关键点 | 完成标志 |
| --- | --- | --- | --- |
| 1 | 我做你看 | 边做边讲"为什么这么做"，不只讲步骤 | 对方能复述原理 |
| 2 | 你做我看 | 让对方动手，全程不插手 | 完整做一遍 |
| 3 | 我点评 | 先肯定 1 点，再指 1-2 个关键问题 | 对方知道差在哪 |
| 4 | 我再做 | 把点评的问题做正确示范 | 对方看到差异 |
| 5 | 你再做 | 修正后重做 | 错误点消除 |
| 6 | 再点评 | 达标确认 or 回到 4（最多循环 3 次） | 达标放行 |
| 7 | 放手独立做 | 交完整任务，仅约定检查节点，中途不干预 | 独立交付合格 |
| 8 | 总结并教会他人 | 让对方复盘并教给下一个新人 | 能带出第 2 个人 |

第8步是关键：能教别人才说明真正内化了，同时实现人才批量复制。只教不放=永远离不开你，只放不教=放任。

## 工作流程

1. 确认教什么活、教谁、达到什么标准（照 task-dispatch-checker 的结果定义补全）。
2. 生成八步培养计划表：每步的动作、时间、验收标准、当前停在哪一步。
3. 每次用户反馈"教过了/他做完了"，推进到下一步并给该步话术。
4. 第 3、6 步给具体点评话术；第 7 步给授权与检查节点；第 8 步给复盘提问清单。

## 常用话术

- 点评（第 3/6 步）："对的地方：XXX。差的地方：XXX，差的后果是 XXX。看我再做一遍这个点。"
- 放手（第 7 步）："这次全权你来，我不插手。10-15 12:00 给我看一次中期进度，其他你自己定。"
- 复盘提问（第 8 步）："这件事最难的三步是什么？为什么？如果重来你会改哪里？你要教给别人，你会先讲什么？"

## 考核绑定提醒（默认附带）

- "不培养接班人就不提拔"：带教产出计入管理者考核。
- 师徒制纳入考核：师傅有带教津贴/积分，徒弟出师（第 8 步完成）师傅才算完成。
- 带教不是帮忙，是职责。

## 输出格式

```
【培养对象】<人> → 【目标】<学会什么，到什么程度>
【当前阶段】第 X 步：<该步动作 + 话术>
【计划表】八步 × (动作/时间/验收) —— 已完成打勾
【考核绑定】师傅 <人> 的带教产出：……
```

## 示例

用户："小王要接手皮带撕裂检测的现场调试，怎么带？"

```
【培养对象】小王 → 【目标】独立完成现场调试并能带下一个人
【当前阶段】第 1 步：我做你看
  现场调试一次，边做边讲："矩形识别参数为什么这么设、报警阈值 0.65 的来历、
  现场光线变了先调哪个参数"。让他记录《调试要点清单》。
【计划表】
  1 我做你看（10-14 现场）✓~
  2 你做我看（10-16 同类工况）
  3 我点评（当天）
  4-6 做→评→再做（10-18，最多 3 轮）
  7 放手独立做（10-22 独立接一次调试，10-21 中期看一次）
  8 总结并教会他人（10 月底复盘 + 教新来的李XX）
【考核绑定】小王出师（第 8 步）计入张工带教绩效
```

## 踩坑提醒

1. **只示范不让他动手** → "看我做三遍不如自己做一遍"。
2. **只说"不对"不说"怎么改"** → 纠偏必须给示范，不能只给评价。
3. **放手=不管** → 放手是"不盯过程"，但检查点必须设。
4. **不要求第8步** → 不教别人=你永远是唯一的培训机器，永远带不完。
5. **培养接班人怕被替代** → 不培养接班人就不提拔——你上不去是因为没人能接你的位。
