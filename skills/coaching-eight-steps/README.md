# 带人教练流程（coaching-eight-steps）

用八步教练法带新人、培养骨干、做交接：示范→反馈→放手→再教，并提醒考核绑定。

## 对应培训模块

八步教练法 · 人才复制口诀 · 传帮带机制（方法层）

## 触发条件

带新人、培养骨干、把一件活教给别人。触发词：`带人` `带新人` `培养` `教练` `教徒弟` `传帮带` `师徒` `八步教练` `交接`

## 八步流程

| 步 | 动作 | 关键点 | 完成标志 |
|----|------|--------|----------|
| 1 | 我做你看 | 边做边讲"为什么" | 对方能复述原理 |
| 2 | 你做我看 | 全程不插手 | 完整做一遍 |
| 3 | 我点评 | 先肯定 1 点再指 1-2 个问题 | 对方知道差在哪 |
| 4 | 我再做 | 错误点正确示范 | 看到差异 |
| 5 | 你再做 | 修正后重做 | 错误点消除 |
| 6 | 再点评 | 达标放行，最多循环 3 次 | 达标确认 |
| 7 | 放手独立做 | 只约定检查节点 | 独立交付合格 |
| 8 | 总结并教会他人 | 复盘 + 教下一个人 | 能带出第 2 个人 |

第8步是关键：能教别人才算真正学会，同时实现人才批量复制。只教不放=永远离不开你，只放不教=放任。

口诀："我说你听，你说我听；我做你看，你做我看；你放手做，你教别人。"

## 常用话术

- 点评："对的地方：XXX。差的地方：XXX，后果是 XXX。看我再做一遍这个点。"
- 放手："这次全权你来，我不插手。<日期> 给我看一次中期进度。"
- 复盘："最难的三步是什么？重来会改哪里？你要教给别人，先讲什么？"

## 输出物

培养对象 + 目标 + 当前阶段（含该步话术）+ 八步计划表（动作/时间/验收）+ 考核绑定提醒。

## 考核绑定（默认附带）

- 不培养接班人就不提拔：带教产出计入管理者考核
- 师徒制纳入考核：徒弟出师（第 8 步完成）师傅才算完成
- 只教不放=永远离不开你；只放不教=放任

## 示例

输入："小王要接手皮带撕裂检测的现场调试。"

输出：第 1 步现场示范（边做边讲参数来历）→ 计划表排至第 8 步（10 月底教新人）→ 出师计入师傅带教绩效。

## 踩坑提醒

1. 只示范不让他动手 → "看我做三遍不如自己做一遍"
2. 只说"不对"不说"怎么改" → 纠偏必须给示范，不能只给评价
3. 放手=不管 → 放手是"不盯过程"，但检查点必须设
4. 不要求第8步 → 不教别人=你永远是唯一的培训机器
5. 培养接班人怕被替代 → 不培养接班人就不提拔
