# 责任锁定与承诺管理清单

核心原则：责任稀释定律——人越多，个人责任感越弱；责任跳跃定律——上一级代做一次，责任永久跳级。

## 检查清单（逐项过，输出✅/❌+证据）

### A. 一对一锁定
- [ ] 每项任务责任人是**唯一一个名字**（不是"我们/大家/XX 部门/相关人等"）
- [ ] 责任人自己确认接了（不是被代表）
- [ ] 没有"共同负责"——共同负责=没人负责，必须拆成子任务各归各人

### B. 责权利等边三角形
- [ ] 责：任务边界写清，什么算完成
- [ ] 权：给够对应权限（调配人/钱/审批权），有权无责会乱、有责无权会瘫
- [ ] 利：干成有什么（绩效/奖金/晋升挂钩），干不成有什么（考核/后果）
- 三边必须等长：任一项缺失或不对等，标红提示

### C. 承诺式管理（八特征抽样检查）
- [ ] 目标明确可量化 [ ] 时限明确 [ ] 公开承诺（会上说/书面签）
- [ ] 有奖惩约定 [ ] 有检查节点 [ ] 可验收标准
- [ ] 承诺是自愿确认的（非强行摊派） [ ] 有复盘约定

### D. 越级规则
- [ ] 可越级检查，不可越级指挥（上级可查下属的下属，但不能绕过直接上级派活）
- [ ] 可越级申诉，不可越级汇报（有冤可越级申，但正常汇报走直属线）
- 违反任一条，立即标红并给出纠正话术

## 输出格式

```
【清单结果】A x/3 · B x/3 · C x/8 · D x/2
【❌ 问题项】逐条：问题 + 原文证据 + 修正建议
【任务锁定表】
| 任务 | 责任人(唯一) | 交付标准 | 截止 | 权限 | 奖惩 | 检查节点 |
【需当场确认的话】<会议收口话术>
```

## 会议收口话术模板

```
"刚才定的事，我复述一遍：<任务>由 <姓名> 一个人负责，
<日期> 前交付 <验收标准>，需要的 <权限> 今天给到位。
干成 <奖励/认可>，干不成 <考核后果>。
<姓名> 你自己确认：能不能接？有没有条件没满足？
中途 <节点> 我检查一次。"
（让责任人当众口头确认）
```

## 示例

用户："下周安全检查，我们几个一起弄一下，有问题找我。"

❌ 检出：A "我们几个"责任稀释（0/3）；B 无权无利；D "找我"可能造成越级指挥。
修正：
```
【任务】完成 10 月安全检查并出具整改清单
【责任人】王XX（一个人）
【交付标准】检查表全项覆盖 + 整改清单（问题/措施/责任人/期限）
【截止】10-17 17:00，10-15 12:00 交中期进度
【权限】可调用质检办 2 人半天；整改通知单代我签发
【奖惩】计入本月绩效 +1 项；漏检一项按质检考核细则扣分
```
收口：让王 XX 当场确认能否接、还缺什么条件。

## 踩坑提醒

1. **"大家一起努力"** → "大家"=没人，必须落到人头。
2. **只分责不分权** → 让人负责却不给调动资源的权力，等于让他背锅。
3. **会上说了会下没记** → 口头共识三天后蒸发，必须有书面记录。
4. **中间不检查只等结果** → 等截止日才发现做偏了，来不及救。
5. **越级指挥还觉得高效** → 一次越级指挥，中间管理层的威信就折损一次。
