# 责任锁定与承诺管理清单（responsibility-lock）

开会定任务、项目启动、跨部门协作前的责任自检清单：一对一锁定、责权利等边三角形、承诺式管理、越级规则。

## 对应培训模块

责任稀释定律 · 责任跳跃定律 · 责权利等边三角形 · 承诺式管理八特征（责任层）

## 触发条件

开会定任务、项目启动、跨部门协作分工、追责或责任不清。触发词：`责任锁定` `承诺管理` `分工` `定责任人` `开会定任务` `越级` `责权利` `责任稀释`

## 四组检查项

**A. 一对一锁定**
- 责任人是唯一一个名字（不是"我们/大家/XX 部门"）
- 责任人自己确认接了
- 无"共同负责"——共同负责=没人负责，必须拆成子任务各归各人

**B. 责权利等边三角形**
- 责：任务边界与完成标准
- 权：对应权限（人/钱/审批权）
- 利：奖惩挂钩——三边必须等长

**C. 承诺式管理八特征**
目标可量化 / 时限明确 / 公开承诺 / 奖惩约定 / 检查节点 / 可验收 / 自愿确认 / 复盘约定

**D. 越级规则**
- 可越级检查，不可越级指挥
- 可越级申诉，不可越级汇报

## 输出物

清单结果（A x/3 · B x/3 · C x/8 · D x/2）+ ❌ 问题项与修正 + 任务锁定表 + 会议收口话术。

会议收口话术模板：

```
"刚才定的事我复述一遍：<任务>由 <姓名> 一个人负责，
<日期> 前交付 <验收标准>，需要的 <权限> 今天给到位。
干成 <奖励>，干不成 <考核后果>。
<姓名> 你自己确认：能不能接？缺什么条件？
中途 <节点> 我检查一次。"（要求责任人当众口头确认）
```

## 示例

输入："下周安全检查，我们几个一起弄一下，有问题找我。"

❌ "我们几个"责任稀释（A 0/3）；❌ 无权无利（B）；⚠️ "找我"可能越级指挥（D）。
→ 修正为单责任人 + 交付标准 + 权限 + 奖惩 + 检查节点，并要求当众确认。

## 踩坑提醒

1. "大家一起努力" → "大家"=没人，必须落到人头
2. 只分责不分权 → 让人负责却不给调动资源的权力，等于让他背锅
3. 会上说了会下没记 → 口头共识三天后蒸发，必须有书面记录
4. 中间不检查只等结果 → 等截止日才发现做偏了，来不及救
5. 越级指挥还觉得高效 → 一次越级指挥，中间管理层的威信就折损一次
