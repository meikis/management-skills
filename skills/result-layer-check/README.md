# 结果分层自查（result-layer-check）

交付方案/报告/材料前，判断落在基本圈/期望圈/超值圈哪一层，指出差距并给出"再跳一层"的具体动作。

## 对应培训模块

三种工作圈分层理论 · 九段秘书/九段销售/九段班组长（思维层/方法层）

## 触发条件

用户交一份方案、报告、汇报材料前想确认质量层级。触发词：`自查` `三种工作圈` `够不够好` `这个方案怎么样` `交付前检查` `超值圈` `九段` `结果分层`

## 三层定义

| 圈层 | 标准 | 典型表现 | 接收方感受 |
|------|------|----------|----------|
| 基本圈 | 做完 | 交了，但缺数据缺结论，领导还要追问 | "嗯，交了。"（无感） |
| 期望圈 | 做好 | 完整、通顺、能直接用 | "还行，符合要求。"（满意） |
| 超值圈 | 超越预期 | 附结论建议、备选方案、风险预判、下一步动作 | "这个人靠谱！"（惊喜） |

九段对照：秘书 递名片→…→老板智囊；销售 记客户→…→建生态；班组长 看现场→…→育文化。

## 跳层公式

- 基本圈→期望圈 = 补齐缺失要素 + 达到标准质量
- 期望圈→超值圈 = 在"做完"基础上，多做以下任一项：
  ① 提供决策建议 ② 预判风险 ③ 提供可复用工具/模板 ④ 用数据说话 ⑤ 换位思考

## 检查五维度

结果定义清晰度 / 数据支撑 / 结论与建议 / 风险预判 / 可执行性（下一步动作）

## 输出物

```
【当前圈层】基本圈/期望圈/超值圈（置信度 X/10）
【判定依据】✅ 已有证据 / ❌ 缺失点（具体到章节/数据）
【跳层动作】按性价比排序，最多 5 条
【一句总结】现在能干什么、补完能干什么
```

## 示例

输入："季度总结：合格率 98.2%，比上季好，下季继续努力。"

判定：基本圈（完成动作，无结论无依据）。❌ 无对比数据、❌ 无 1.8% 不合格归因、❌"继续努力"不是动作。
跳层动作：① 补上季数据做对比（→期望圈）② 拆 Top3 不合格原因 ③ 下季目标定量化（→冲超值圈）④ 预判新供应商来料风险。

## 踩坑提醒

1. "完成了=做好了" → 完成是基本圈，做好是期望圈
2. 超值≠加班堆量 → 超值不是"多写10页"，而是"多提供一个决策维度"
3. 不知道期望在哪 → 问接收方"你最想从这份材料里看到什么"
4. 每次都靠灵感跳层 → 把超值动作固化成检查清单，每次交付前过一遍

## 硬规则

圈层判断必须给证据（引用原文位置/缺失点），禁止只说"还不错/需要加强"。
