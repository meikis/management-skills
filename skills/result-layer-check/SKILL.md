# 结果分层自查（三种工作圈 + 九段体系）

核心原则：同样的动作，落在不同圈层，价值差十倍。

## 三层定义

| 圈层 | 标准 | 典型表现 | 接收方感受 |
| --- | --- | --- | --- |
| 基本圈 | 做完（完成动作） | 交了，但缺数据、缺结论、领导还要追问 | "嗯，交了。"（无感） |
| 期望圈 | 做好（达到预期） | 内容完整、逻辑通、能直接用，无惊无险 | "还行，符合要求。"（满意） |
| 超值圈 | 超越预期（带来额外价值） | 附结论建议、备选方案、风险预判、下一步动作，领导不用再想 | "这个人靠谱！"（惊喜） |

九段对照（选贴近的角色校准）：
- 九段秘书：1 递名片 → 3 会准备 → 5 会跟踪 → 7 会判断 → 9 老板智囊
- 九段销售：1 记客户 → 3 懂需求 → 5 做方案 → 7 谈战略 → 9 建生态
- 九段班组长：1 看现场 → 3 抓质量 → 5 带队伍 → 7 建机制 → 9 育文化

## 工作流程

1. 获取交付物（文件或用户描述）。用户没给原文时先索要；只有描述时按描述判定并注明置信度。
2. 按五维度打分：结果定义清晰度 / 数据支撑 / 结论与建议 / 风险预判 / 可执行性（下一步动作）。
3. 判定当前圈层，引用证据（原文位置/缺失点），禁止空泛评价。
4. 输出"跳一层"动作清单（按成本从低到高排序，最多 5 条）。
5. 若用户要求，直接代为补写缺失部分。

**跳层公式**：
- 基本圈→期望圈 = 补齐缺失要素 + 达到标准质量
- 期望圈→超值圈 = 在"做完"基础上，多做以下任一项：① 提供决策建议 ② 预判风险 ③ 提供可复用工具/模板 ④ 用数据说话 ⑤ 换位思考

## 输出格式

```
【当前圈层】基本圈 / 期望圈 / 超值圈（置信度 X/10）
【判定依据】
- ✅ <已有证据>
- ❌ <缺失点，具体到章节/数据>
【跳层动作】（按性价比排序）
1. <最小改动、最大提升>
2. …
【一句总结】<这段材料现在能干什么、补完能干什么>
```

## 示例

用户："明天汇报的季度质检总结，就这几段：合格率 98.2%，比上季好，下季继续努力。"

判定：基本圈（完成动作，无结论无依据）。置信度 9/10。
- ❌ "比上季好"无对比数据
- ❌ 无不合格 1.8% 的归因
- ❌ "继续努力"不是动作

跳层动作：
1. 补上季合格率数字做对比（→ 升期望圈）
2. 拆 1.8% 不合格的 Top3 原因 + 占比
3. 下季目标定量化："合格率 98.5%，措施：XX 工装更换 + 首件双检"（→ 冲超值圈）
4. 预判风险：新供应商来料波动，附备选方案

## 踩坑提醒

1. **"完成了=做好了"** → 完成是基本圈，做好是期望圈。
2. **超值≠加班堆量** → 超值不是"多写10页"，而是"多提供一个决策维度"。
3. **不知道期望在哪** → 最简单的办法：问接收方"你最想从这份材料里看到什么"。
4. **每次都靠灵感跳层** → 把超值动作固化成检查清单，每次交付前过一遍。

## 硬规则

- 圈层判断必须给证据，禁止只说"还不错/需要加强"。
- 用户没给交付物原文时，先索要；只有描述时按描述判定并注明置信度。
